# EduGlossary — Supermemory Seed

## Project Config
- Astro 4.16.18, static site, Indonesian language
- Education glossary + tech articles
- Build: `npm run build` (astro build && pagefind --site dist)
- Dev: `npm run dev` (localhost:4321)
- Preview: `npm run preview`
- No test framework, no lint config
- TypeScript strict (astro/tsconfigs/strict)
- Path alias: @/* to src/*

## Architecture
- src/content/config.ts — Zod schemas for glossary and articles
- src/content/glossary/*.md — 22 glossary entries
- src/content/articles/*.md — 1 article
- src/components/ — Header, Footer, GlossaryCard, ArticleCard, Breadcrumb
- src/layouts/Layout.astro — single layout with SEO and Pagefind
- src/pages/ — index, about, glossary (index + [slug] + kategori/[category]), articles (same)
- src/utils/ — categoryColors.ts, categoryIcons.ts, slugify.ts

## Key Conventions
- All content in Indonesian (Bahasa)
- slugify() strips accents, replaces & with "dan", lowercases, hyphens
- Categories hardcoded (6 total)
- Cards: accent bar + badge + hover
- Trailing slash URLs
- Static output, directory format
- Pagefind for search (post-build)
- JSON-LD: DefinedTerm for glossary, Article for articles

## Content Schema
Glossary: term, shortDefinition, category, letter, updatedDate, relatedTerms[]
Articles: title, description, category, tags[], author, coverImage?, publishedDate, updatedDate?, draft
