## 5. AI-Search Readiness Layer

### Answer Block (Under First H2, 130–170 words)
> **Machine learning is a subset of artificial intelligence where computers learn patterns from data without being explicitly programmed. Instead of writing rules for every scenario, you feed the system examples (training data), and it builds a model that can make predictions on new, unseen data. The three main types are supervised learning (learning from labelled examples like "spam/not spam"), unsupervised learning (finding hidden structures in unlabelled data like customer segments), and reinforcement learning (learning optimal actions through trial and error, like a robot learning to walk). Common algorithms include linear regression for predicting numbers, decision trees for interpretable rules, and neural networks for complex patterns. Machine learning powers everyday applications — email spam filters, recommendation engines, fraud detection, and voice assistants — making it one of the most impactful technologies of the 21st century.**
